# 课表与视图

本文档介绍托盘菜单中与课表显示和视图控制相关的菜单项。

## 当前地区

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | 空字符串 |

设置天气查询的地理位置（城市名称），如“南京”、“上海”，使用英文（拼音）也可，如“Nanjing”、“Shanghai”。用于和风天气 API 查询。对于存在歧义的地区（比如“吉林”），可以写为“吉林/吉林”或者“Jilin/Jilin”，即通过“省/市”的格式来消除歧义。

如果您想要精确到区，**应当** 写“Nanjing/Gulou”、“南京/鼓楼”，而 **不是** “江苏/南京/鼓楼”，最多只能有一个斜杠。

## 更新课表

| 属性 | 值 |
|------|-----|
| 类型 | 按钮 |

立即强制从服务端拉取最新课表：这是客户端唯一携带 `version=0` 的入口，必定绕过边缘缓存回源取得最新数据，任何模式下都可用。

与之相对，启动、日程轮换、`SyncConfig` 推送、WebSocket 重连等其余时机都会携带手中的版本号，由边缘缓存决定是否回源（详见[云端与更新](./cloud-update)）。因此当管理端修改了配置而客户端迟迟未更新时，点这里即可立即刷新。

## 配置课表

| 属性 | 值 |
|------|-----|
| 类型 | 按钮 |

临时修改当前某节课的科目，仅本次运行有效，重启后恢复。点击后弹出两步对话框：

1. 选择要修改的课程时段
2. 从所有可用科目中选择替换科目

此修改仅在当前运行实例的内存中生效，不会持久化或同步到服务端。

## 矫正计时

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | `0` |

设置课表计时与系统时间的偏移秒数。正数为延后，负数为提前。用于校正客户端显示时间与实际时间的偏差。不过，由于现代计算机通常具备完整、及时的时间同步功能，如果软件时钟与学校时钟存在差异，往往是学校时钟的偏差。

## 切换日程

| 属性 | 值 |
|------|-----|
| 类型 | 子菜单 |

强制使用本周某一天的课表替代当天课表，自动在日期变化后重置。菜单中提供“重置至当前日期”选项以立即恢复。

此功能用于调休，但仍然建议您通过网页管理端配置自动任务的方式处理调休。本功能是一个“历史遗留”之物。
