# 云端与更新

本文档介绍托盘菜单中与云端连接和自动更新相关的菜单项。

> [!WARNING]
>
> 「连接云端」开关已于 2026-09 移除：本地配置模式下线后，客户端始终从云端拉取课表，窗口是否显示改由服务端下发的启动行为与本地缓存共同决定，不再受该开关控制。若你的菜单中仍看到该项，说明客户端版本较旧，升级后即消失。

## 更新源（可选）

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | 空（使用默认对象存储镜像目录 `https://ningbo.rainyun.oss.ymbit.cn/AstraSchedule/latest/`） |

设置自定义自动更新镜像源地址，需指向包含 `latest.yml`（Windows 7/8.1 通道）与 `win10.yml`（Windows 10+ 新版 Electron 通道）的目录。修改后需重启应用生效。历史默认源（`hubproxy.khbit.cn` 及早期 OSS 目录）会在启动时自动迁移到当前默认源，自定义源不受影响。

## 检查更新

| 属性 | 值 |
|------|-----|
| 类型 | 按钮 |

立即手动检查是否有新版本可用。仅在打包版本（`app.isPackaged`）中生效，开发模式下会提示"开发模式下不检查更新"。

## 自动更新

| 属性 | 值 |
|------|-----|
| 类型 | 复选框 |
| 默认值 | 开启 |

是否启用自动更新检测。开启后，应用启动 3 秒后自动检查更新。

## 云端服务

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | `class.getastra.cn` |

设置后端 API 服务器地址。修改后不会立即重新拉取配置，需重新获取课表（托盘「更新课表」）或重启客户端后生效。

## 安全连接

| 属性 | 值 |
|------|-----|
| 类型 | 复选框 |
| 默认值 | 开启 |

是否使用 HTTPS/WSS 加密连接。关闭后使用 HTTP/WS。

## 所在班级

| 属性 | 值 |
|------|-----|
| 类型 | 输入框 |
| 默认值 | `39/2023/1` |

设置班级标识，格式为 `学校/年级/班级`（如 `39/2023/1`）。修改后触发 WebSocket 重连。

## 刷新天气

| 属性 | 值 |
|------|-----|
| 类型 | 按钮 |

立即手动刷新天气数据。

## 课表拉取与版本缓存

客户端每次拉取课表都会携带手中的**数据版本号**，服务端（及前面的边缘缓存节点）据此判断数据是否变化：未变化返回 `304 Not Modified`，客户端直接复用本地缓存，不产生流量。

- **启动复用**：启动时从本地版本索引恢复上次的版本号，避免每次启动都全量回源
- **手动强制回源**：托盘「更新课表」是唯一会带 `version=0` 强制回源的入口，一定拿到最新数据；其余时机（启动、日程轮换、`SyncConfig` 推送、WebSocket 重连、失败重试）都携带版本号，由边缘决定是否回源
- **版本串格式**：`<数据最后变更时间戳>:<当前教学周>:<预测下一次更新时间>`，第三段仅供边缘计算缓存有效期，源站校验时忽略

## 离线缓存

在线成功拉取课表后，数据会写入本地缓存目录（`用户数据目录/schedule-cache/`，保留最近 5 个版本及版本索引）。断网或云端不可用时，客户端自动回落显示缓存课表，托盘提示会显示离线状态；网络恢复后按退避策略重试并自动切回在线状态。
